What Is a PWA? How to Add Web Games to Your Home Screen

By Agus Nugraha · ENKES Project

What Does PWA Mean?

PWA stands for Progressive Web App. It is a website that can behave like an app. It can be added to your home screen, open in its own window without the browser address bar, and sometimes keep working with a weak connection.

Why It Is Useful for Games

A PWA gives you a one-tap icon on your phone without going through an app store. It takes up very little space and always opens the latest version. Puzzle King is built to work this way.

How to Add a Game on Android (Chrome)

1. Open the game page in Chrome.

2. Tap the three-dot menu in the top-right corner.

3. Choose "Add to Home screen" or "Install app".

4. Confirm the name and tap Add.

5. Find the new icon on your home screen and open it like any other app.

How to Add a Game on iPhone (Safari)

1. Open the game page in Safari.

2. Tap the Share button.

3. Scroll down and choose "Add to Home Screen".

4. Tap Add in the top-right corner.

Troubleshooting

If you do not see the install option, make sure you are using an up-to-date browser and that the page has fully loaded. The exact wording of the menu can differ slightly between browsers and versions.

Removing It Later

A PWA can be removed like any app: press and hold the icon and choose Remove or Uninstall. Nothing else on your phone is affected.
