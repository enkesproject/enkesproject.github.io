Enkes Project

Halo! Saya developer indie yang senang membuat game dan aplikasi sederhana. Semua proyek di sini saya kerjakan secara mandiri, mulai dari ide, desain, sampai coding — sebagian besar berbasis HTML5 sehingga bisa langsung dimainkan di browser tanpa perlu instal apa pun.

Game Saya

Kelinci Pemberani

Game platformer kasual di mana kamu mengendalikan seekor kelinci yang harus melompat dari satu platform ke platform lain sambil mengumpulkan koin. Terdiri dari 10 level dengan tingkat kesulitan yang meningkat, cocok dimainkan santai kapan saja.

Puzzle King

Game puzzle bergaya susun blok klasik, dikemas ulang dengan tampilan dan fitur baru. Uji kecepatan dan strategi kamu dalam menyusun blok sebelum layar penuh. Tersedia untuk dimainkan langsung di browser maupun diunduh sebagai aplikasi.

Cara Main

Semua game di situs ini bisa dimainkan gratis langsung dari browser, baik di HP maupun komputer. Cukup klik link game yang ingin dimainkan, game akan langsung terbuka tanpa perlu instalasi.

Tentang Kami

Enkes Project adalah proyek pribadi saya untuk belajar dan bereksperimen dengan pengembangan game. Saya percaya siapa pun bisa membuat game sederhana yang menyenangkan meski dikerjakan sendirian dan bertahap. Terima kasih sudah mampir dan mencoba game-game buatan saya!
