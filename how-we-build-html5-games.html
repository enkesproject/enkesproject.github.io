How We Build HTML5 Games as a Solo Developer

By Agus Nugraha · ENKES Project

Why HTML5?

HTML5 lets us make games that run in nearly any browser without installation. That suits our goal of making simple, free games that anyone can open instantly, on a phone or a computer.

From Idea to Prototype

Every game starts with a simple idea, such as "a rabbit that collects coins" or "a puzzle that leads to a battle". We build a rough prototype first, with basic shapes and no polish, to check that the core idea is actually fun.

Drawing With the Canvas

Most of our games use the HTML5 Canvas API, which lets us draw graphics directly on the page with JavaScript. It is lightweight and fast, which helps our games run well even on older phones.

Testing on Real Devices

A game that works on a desktop can feel completely different on a phone. We test touch controls, screen sizes and performance, and adjust until the game feels comfortable to play.

Publishing

Finished games are hosted on GitHub Pages, so they are available at a simple web address. That keeps hosting costs low and lets us update a game quickly when we find a bug.

Listening to Players

Feedback is a big part of the process. If you find a bug or have an idea, please send it through our contact page. Many of our improvements start with a message from a player.
