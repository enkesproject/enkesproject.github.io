ABOUT

One developer, four games, and counting.

Enkes Project is a solo indie game studio. There's no team behind it — every game on this site is designed, drawn, coded, tested and published by one person, working on it alongside everything else life involves.

Why HTML5

Every game here is built with HTML5, which means it runs straight in a browser tab — no store to visit, no install to wait for, no update to download. Open a link and you're playing within seconds, on a phone or a desktop. That accessibility is the whole point: games should be easy to try.

How the games get made

Each project starts as a small idea — a mechanic worth exploring, like linking a puzzle board's outcome to an automatic battle in Rune Gate, or stacking blocks faster and denser in Block Puzzle Extreme. From there it's built level by level, tested on real devices, and refined based on how it actually feels to play, not just how it looks on paper.

What's next

Enkes Project is an ongoing project, not a finished catalog. New games get added over time, and existing ones get revisited and improved — better controls, new levels, or a cleaner look. If you enjoy a game, checking back occasionally is worth it.

Get in touch

Found a bug, have feedback, or just want to say hi? Head over to the contact page — every message is read personally.
